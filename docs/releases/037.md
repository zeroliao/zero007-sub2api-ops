## 变更范围

- IP 管理中的 `proxies` 由软删除改为物理删除，删除时清理 sidecar endpoint，并保留账号外键的既有解绑/级联语义。
- 订阅节点失效、订阅源扫描失败或 sidecar 探测失败时，物理删除订阅代理和 endpoint；订阅源与订阅节点仍保留软删除和扫描结果，用于诊断。
- 订阅节点按自身 `managed_proxy_id` 或 sidecar endpoint 复用代理，回收只允许删除 `source='subscription'` 的资源，避免同地址手工代理被误删。
- 远程 sidecar 对账清理历史软删除订阅代理、孤立 endpoint 和失效订阅资源，释放旧端口（包括 `31011`）。

## 数据影响与回滚

- 本版本没有新增或修改数据库 migration；删除 SQL 在订阅资源回收和 sidecar 对账运行时执行。
- 部署前执行 ops 仓库标准 PostgreSQL/config backup，备份路径写入本记录。
- 物理删除的代理、endpoint 和级联绑定不能通过应用回滚恢复；如需恢复，使用部署前 PostgreSQL dump 手工恢复，或回滚应用后重新导入订阅源。
